# REDLINE · 极限制动

一个单文件的制动测试小游戏：车辆自动加速破百，你在绿灯亮起的瞬间踩死刹车，用最短时间把车稳稳停下。

难点不在「踩下去」，而在**踩多狠**——踩太轻刹不住，踩太狠会把刹车踏板踩断。你得在抓地极限和过压断裂之间找到那条窄缝。

打开 `brake-master.html` 就能玩，零依赖、零构建。

---

## 玩法

1. 点击「开始测试」，车辆自动加速。
2. 越过 **100 km/h** 后绿灯亮起，**立刻踩下刹车**。
3. 在 100 km/h 到 0 的过程中把车速压下去，别让刹车力冲破过压线。
4. 车辆停稳即通关，用时越短越好。个人最快成绩记录在本地浏览器。

### 操作

| 操作 | 方式 |
|---|---|
| 踩下刹车 | 按住画面下方「踩下刹车」按钮，或按住 **空格键** |
| 抬起刹车 | 松开按钮 / 松开空格 |
| 暂停 | 右上角 ❚❚ |
| 静音 | 右上角 ♪ |

按住会持续加力，松开则快速泄力。触屏、鼠标、键盘都能玩。

## 判定规则

三种情况判定失败：

| 失败 | 触发条件 | 结算标题 |
|---|---|---|
| 踩早了 | 车速未到 100 km/h 就踩下刹车 | 踩早了 |
| 力度过大 | 刹车力冲过过压线，且持续超过引信时限 | 力度过大 |
| 爆表了 | 车速一路冲到仪表上限 200 km/h | 爆表了 |

成功停稳则记为 `TEST PASSED`，成绩即「从 100 km/h 到完全停稳」的用时。

结算页给出：反应时间（绿灯 → 踩下）、入刹速度、峰值力度，以及本局的**车速 / 力度双曲线图**（竖虚线为计时起点，红点标注力度峰值，红色虚线为过压线）。

## 物理模型

所有数值都集中在 `<script>` 开头的「参数」区，改常量即可调手感。

### 1. 制动力 → 减速度

```
减速度 = 有效制动力 × DECEL_PER_N      // DECEL_PER_N = 9.8 / 1500
```

踩到抓地极限 1500 N 时约 9.8 m/s² ≈ 1g。**超过 1500 N 不再有任何额外制动收益**，多踩只是白费力气、徒增断裂风险。

### 2. 两段式腿力模型（核心）

这是整个手感的关键。人的腿力不是无限的，踏板踩到底之后就再也加不动了：

| 阶段 | 条件 | 加力速率 |
|---|---|---|
| 起脚段 | `力 < KNEE_N` (1580) | `RATE_UP` = 1050 N/s，一路冲上去 |
| 硬挤段 | `力 ≥ KNEE_N` | `min(SQUEEZE, RATE_UP × (1 − (力/CEIL_N)⁴))`，约 60 N/s |

```
const rate = 力 < KNEE_N
  ? RATE_UP
  : Math.min(SQUEEZE, RATE_UP * (1 - Math.pow(Math.min(1, 力/CEIL_N), 4)));
力 += rate * dt;
```

效果：起脚 1.5 s 左右摸到抓地极限，之后每 0.5 s 只涨 30 N 左右，**全力一脚的峰值自然落在 16xx N 量级**，而不是无限往上飙。

注意这里**没有硬钳制**（没有 `Math.min(上限, ...)`），峰值不会被截成同一个数字，而是随你按住多久、什么时候松手连续变化。

抬脚泄力速度是 `RATE_DOWN` = 2000 N/s，比加力快得多，所以能快速从过压区脱身——这是自救的基础。

### 3. 抓地极限与 ABS

刹车力超过 `GRIP_N` (1500 N) 后 ABS 介入：

```
kick = ABS_KICK × (1 − absPhase / ABS_PERIOD)     // 每次回弹最多卸掉 190 N
有效制动力 = max(0, min(刹车力, GRIP_N) − kick)
```

ABS 约 13 Hz 反复卸压，于是踏板回弹、车身抖动，音效配合触发。

### 4. 过压引信

刹车力触到 `BREAK_N` (1600 N) 即点燃断裂引信，随机 **0.5 ~ 1.5 s** 后踏板支架断裂，判定失败。

- 在时限内把力压回 1600 N 以下，引信会**熄灭**，之后可以重新点燃。
- 所以正确打法是「点刹式」操作：冲过线立刻回一点，别硬撑。

### 5. 车速与牵引力

```
牵引力系数 = max(0, 1 − 有效制动力 / ENGAGE_N)      // ENGAGE_N = 300
新速度 = 速度 + (ACCEL_HI × 牵引力系数 − 有效制动力 × DECEL_PER_N) × dt
```

松开刹车后车辆会重新加速，一路冲到 200 km/h 就爆表。所以犹豫太久一样会输。

## 参数速查表

| 常量 | 默认值 | 含义 | 调它的效果 |
|---|---|---|---|
| `GRIP_N` | 1500 | 抓地极限 / ABS 介入阈值 | 调低更早出 ABS，制动增益上限下降 |
| `BREAK_N` | 1600 | 过压断裂线 | 调高更宽容，调低更容易踩断 |
| `FSCALE_N` | 1600 | 力度条满量程（仅显示） | 只影响力度条刻度，不影响物理 |
| `RATE_UP` | 1050 | 起脚加力速度 N/s | 起脚手感快慢 |
| `KNEE_N` | 1580 | 膝盖点：从哪开始「变肉」 | 调低则更早进入硬挤段，峰值更低 |
| `SQUEEZE` | 60 | 硬挤段速率 N/s | **16xx 区间的斜率，调它改峰值高度** |
| `CEIL_N` | 1800 | 软天花板 | 绝对上限，正常玩不到 |
| `RATE_DOWN` | 2000 | 抬脚泄力速度 N/s | 自救窗口的手感 |
| `ACCEL` / `ACCEL_HI` | 9.0 / 6.0 | 100 km/h 前后自动加速度 m/s² | 提速节奏、难度 |
| `ENGAGE_N` | 300 | 牵引力恢复阈值 | 松脚后车速回升的快慢 |
| `ABS_PERIOD` / `ABS_KICK` | 0.075 / 190 | ABS 回弹周期与卸压量 | 踏板抖动频率与削峰强度 |
| `FUSE_MIN` / `FUSE_MAX` | 0.5 / 1.5 | 过压后随机断裂倒计时 | 过压容错时间 |
| `GAUGE_KMH` | 200 | 仪表上限（爆表线） | 难度上限 |

调参时建议先动 `SQUEEZE`（改峰值）和 `FUSE_MIN/MAX`（改容错），这两个对整体难度影响最大。

## 运行

没有任何构建步骤和依赖，双击打开即可：

```bash
open brake-master.html          # macOS
xdg-open brake-master.html      # Linux
```

需要本地服务器的话（部分浏览器对 `file://` 的字体或存储策略更严）：

```bash
python3 -m http.server 8080
# 然后访问 http://localhost:8080/brake-master.html
```

字体从 Google Fonts CDN 加载（Chakra Petch / Oswald），离线时会回退到系统无衬线字体，不影响功能。

## 技术栈与实现要点

纯原生三件套，无框架、无打包器。

- **渲染**：主场景用 Canvas 2D 绘制（远景山体剪影、道路、速度相关镜头俯仰与抖动）。
- **仪表 UI**：DOM + CSS，速度弧线用 SVG `pathLength` + `stroke-dashoffset` 驱动，避免每帧重排。
- **曲线**：`teleCvs` / `resCvs` 两块独立 Canvas，实时遥测是 6 s 滑动窗口。
- **纵横比与高分屏**：canvas 尺寸按 `devicePixelRatio` 处理（上限 1.75，兼顾清晰度与性能）。
- **音效**：WebAudio 程序化合成（振荡器 + 噪声），无音频文件。引信警报、ABS 滴答、轮胎尖叫都是实时生成的。
- **布局**：`env(safe-area-inset-*)` 适配刘海屏，`touch-action: none` + `overscroll-behavior: none` 防止移动端误触与下拉刷新。

### 两处值得一提的视觉细节

- **力度条**：满量程 1600 N。顶穿之后条子会封顶并进入溢出状态（变红脉冲 + 右上角「超 +xx」标记），但旁边的大号数字显示的是**真实值**，不会被截断。
- **曲线纵轴自适应**：图表纵轴下限 1600 N，会按本局真实峰值以 200 N 为步长自动上探（1601→1800、2125→2200），所以超压段不会被削平；同时叠加一条 1600 N 过压虚线和力度峰值红点。

## 已知限制

- 单局单人，无排行榜（最快成绩仅存 `localStorage`）。
- 满屏游戏，未针对超宽屏做专门布局。
- 键盘只绑定了空格；触屏多指按住的行为未定义。
- 暂停只冻结物理，不冻结已播放的音效尾音。
